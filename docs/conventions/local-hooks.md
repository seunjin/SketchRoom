# 로컬 Git Hooks 정책

로컬 Git hooks는 커밋이나 push 전에 기본 검증을 자동으로 실행하기 위한 장치다.

SketchRoom에서는 추후 `lefthook` 도입을 권장한다. 다만 초기 워크스페이스 단계에서는 의존성과 설정을 늘리지 않기 위해 아직 설치하지 않는다.

## 도입 판단 기준

다음 조건이 갖춰지면 `lefthook`을 도입한다.

- `pnpm lint`와 `pnpm build`가 안정적으로 동작한다.
- 테스트 명령이 정리되어 있다.
- PR 전에 반복적으로 놓치는 검증 항목이 생긴다.
- 혼자 작업하더라도 실무형 작업 흐름을 강제하고 싶다.

## 권장 훅

초기 도입 시에는 가볍게 시작한다.

```txt
pre-commit: pnpm lint
pre-push: pnpm build
```

테스트가 정리된 뒤에는 `pre-push`에 관련 테스트를 추가한다.

## 도입하지 않는 이유

현재는 프로젝트 초기 구성 단계라서 hook 도구를 바로 넣으면 핵심 목표보다 도구 설정이 먼저 커질 수 있다.

따라서 지금은 문서로 정책만 정리하고, WebSocket 서버와 프론트 기본 흐름이 생긴 뒤 별도 PR에서 도입한다.
